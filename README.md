# Bento Grid Project

![Design preview for the Bento Grid project](./preview.jpg)

## Welcome! 👋

Thank you for exploring this Bento Grid project.

This project is designed to help improve your front-end development skills by building a responsive grid layout using HTML and CSS.

**To complete this project, you should have a good understanding of HTML and CSS.**

## Project Overview

The goal of this project is to create a responsive bento grid layout that closely matches the provided design.

Your users should be able to:

- View an optimal layout for the interface depending on their device's screen size.

### Key Features

- On desktop, the two components in the left column are aligned at the bottom.
- On mobile, these components are repositioned to the bottom of the layout.

This project is a great opportunity to practice CSS Grid and responsive design techniques.

## Resources

The design files for this project are located in the `/design` folder. Both mobile and desktop versions are provided in JPG format. Use your best judgment for styles like `font-size`, `padding`, and `margin`.

All required assets, including images and fonts, are available in the `/assets` folder. You can use Google Fonts or host the fonts locally.

## Development Workflow

Here’s a suggested workflow for building this project:

1. **Plan your layout**: Review the design files and plan your HTML structure and CSS classes.
2. **Set up your project**: Initialize your project repository and configure it for deployment.
3. **Build the structure**: Write the HTML to create a well-structured layout.
4. **Style the layout**: Start with base styles and progressively add more specific styles.
5. **Test responsiveness**: Ensure the layout adapts well to different screen sizes.
